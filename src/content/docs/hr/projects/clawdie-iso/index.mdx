## Clawdie ISO — Operator USB Image (Glavni projekt)

Bootable USB image — development surface za Colibri + installer za colibri service na bare metal. Ovo je najznačajniji projekt, koji kombinira FreeBSD operativni sustav, ZFS, bhyve virtualizaciju, Bastille jails, i Colibri control plane u jedan prenosiv artifact.

**Tehnološki sklad:** FreeBSD 15 (quindecim) · XFCE · ZFS RAID1 mirror · bhyve · Bastille jails · pgvector · poudriere · age-encrypted seed partition

**Ključni milestone:** [Pogledajte pun build log u wiki →](https://code.smilepowered.org/clawdie/clawdie-iso/src/branch/main/docs)

- Seed partition + age encryption (PIN unlock, nema Vaultwarden)
- Firstboot pipeline: seed decrypt → Pi agent (npm global) → home overlay
- Colibri-daemon (systemd-style, AUTOSPAWN=YES, PostgreSQL + pgvector)
- Mother/Hive arhitektura: colibri-mcp SSH-stdio bridge + tool proxy
- Poudriere package repo + verificirani artifacts (build-manifest.json, check_release_gate)
- Hardverski validirano na Valhala (HP ML350p Gen8)

**Trenutna verzija:** 0.12.0 (objavljeno) → 0.13.0 target (u razvoju: Colibri integration, wiki, OKF)

**Build host:** Valhala — HP ML350p Gen8, FreeBSD 15, `doas`, poudriere bulk builds
