## Pi Harness

**Tehnologije:** Node.js, `@earendil-works/pi-coding-agent` (npm global), Aider

**Opis:** Samostalni, konfigurabilni agent za autonomni razvoj. Primarna izvršna vrstica na Clawdie ISO — instaliran kot npm global s **home overlay** (`.pi/agent/` → `$HOME`). Radi pod Hermes orkestracijom (Hermes=orchestrator, Codex=FreeBSD/ISO, Claude=dizajn, Zot=kodiranje). Zamijenio OpenClaw (Peter Steinberger) kao primjeren harness za Hermes ekosustav.
