## Zot Agent Harness

**Tehnologije:** Rust, NDJSON RPC, Codex/Claude/OpenCode integracija

**Opis:** Agent harness za delegiranje kodnih zadataka. Omogućuje `zot rpc` komunikaciju, subtask delegation, tool-call interception, i multi-agent workflows.

**Uloga:** Osnova za Hermes-BSD multi-agent orkestraciju
