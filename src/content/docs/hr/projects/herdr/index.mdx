## Herdr — Terminal Workspace Manager

**Tehnologije:** Rust, ratatui, PTY, tmux-style sessions

**Opis:** Terminal-native agent runtime i multiplexer. Pokreće odvojene AI agente u pravim zavicima, omoguća priključak/odključak sesija, koristi SSH attach, agent state (blocked/working/done), i API za orkestraciju.

**Status:** Aktivan razvoj, objavljeno na [herdr.dev](https://herdr.dev) · [GitHub](https://github.com/ogulcancelik/herdr)
