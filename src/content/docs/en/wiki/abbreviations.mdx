## How it works

1. **Source of truth**: `docs/wiki/abbreviations.md` in the Colibri repo
2. **OKF frontmatter**: The page has `type: Glossary`, `status: stable`, `stale_after: 2026-12-31`

4. **Lint validation**: `wiki-lint` checks for undefined abbreviations referenced in other wiki pages
5. **Cross-reference**: Other wiki pages link to abbreviations via `[A2A](./abbreviations.md#a2a)` style anchors

### GIS / GURS (Slovenian geodata)

The GIS/dome-planning arc (`gurs-address-lookup-mcp`, the GIS-INTEGRATION-PLAN doc in clawdie-iso, `docs/GLOSSARY-SL.md` §1) queries Slovenian public geodata over WFS. This section covers the English acronym expansions; Slovenian customer-facing display labels for the same domain terms live in `GLOSSARY-SL.md` §1-2 — the two are complementary, not duplicates.

| Term | Stands for | Why it matters here |
|------|------------|---------------------|
| **CRS** | Coordinate Reference System | Which coordinate space a value is in (e.g. EPSG:4326 vs EPSG:3794) — mismatched CRS silently produces garbage coordinates |
| **DMR** | Digitalni model reliefa (digital terrain model) | GURS's terrain-elevation dataset — feeds dome-site ground-slope and shadow-study calculations |
| **EPSG** | European Petroleum Survey Group | Naming authority for CRS codes — EPSG:4326 is WGS84 (lat/lon), EPSG:3794 is Slovenia's national grid (D96/TM) |
| **GURS** | Geodetska uprava Republike Slovenije | Slovenia's geodetic administration — the public authority behind the address register, cadastre, and orthophoto data this arc queries |
| **OPSI** | Odprti podatki Slovenije (Open Data Slovenia) | Slovenia's general government open-data portal (podatki.gov.si) — GURS publishes its orthophoto dataset here; OPSI is the portal, not the orthophoto imagery itself |
| **WFS** | Web Feature Service | OGC standard for querying vector geodata over HTTP (returns feature data, e.g. GeoJSON — unlike WMS, which returns map images) — the protocol `gurs-address-lookup-mcp` speaks to GURS |

### Wiki-Lint Validation

The `wiki-lint` script validates:

1. **Undefined abbreviations** — if a wiki page uses `A2A` but it's not in `abbreviations.md`, lint fails
2. **Dangling references** — links to `abbreviations.md#A2A` must match a table row
3. **Resurrected names** — checks against the naming ledger for old terms that shouldn't reappear

### Adding New Abbreviations

1. Edit `docs/wiki/abbreviations.md` in the Colibri repo
2. Add a row to the appropriate table (Protocols, Infrastructure, GIS, or Colibri internals)
3. Run `./scripts/wiki-to-okf.sh --verify` to update frontmatter and run lint
4. Commit — pre-push hook runs `ci-checks.sh --strict` including wiki-lint
