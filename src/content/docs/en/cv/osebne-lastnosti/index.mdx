title: Personal Qualities
description: Discover my personal qualities and values that guide me in life and work.
---

My personal qualities include exceptional attention to detail, especially in server configurations and open-source systems. I continuously learn new things, which keeps me up-to-date with the latest technology trends. I am persistent in problem-solving, which sometimes makes me a bit stubborn when it comes to advocating for free software. I have a long-term commitment to open-source operating systems like Linux Debian and FreeBSD, which I use as server solutions. I love working in the shell and use tmux to organize my work, although I started with screen early in my learning journey. I began with Windows 3.11 CE edition, but stopped using Microsoft products in 2007, when Windows 7 was released. Since then, I use Debian as my "daily driver" and FreeBSD on some of my servers.
