My personal qualities include exceptional attention to detail, especially when configuring servers and open-source systems. I continuously learn new things, which allows me to stay current with the latest technology trends. I'm persistent in problem-solving, which sometimes makes me a bit stubborn when advocating for open-source software and simple solutions. I've been committed to UNIX/Like operating systems for the long term, such as Linux Debian and FreeBSD. I use them for both desktop systems and server environments (focus on Cloud solutions). I enjoy working in the terminal/shell and use tmux for organizing remote work. SSH has been my ally since early interactions when we still used screen for long processes. My journey of discovering operating systems started with DOS/Windows 3.11 CE edition (for me, a floppy disk isn't just a save icon — we happily swapped installation floppies and cursed at "Bad sector" errors). Today I no longer use Microsoft products. The last interaction with Microsoft products was in 2007 when I still used Windows 7. Since then, I've used FreeBSD and Debian as my "daily driver" on personal desktop systems and server environments.
