## O meni

Pozdravljeni! Moje ime je Samo Blatnik, sem IT podporno osebje z dolgoletnimi izkušnjami servisiranja računalniške opreme. Trenutno se učim Python programski jezik in se preizkušam kot razvijalec programske opreme s pomočjo generativne umetne inteligence. Moja dolgoletna strastjo za tehnologijo in inovacije me je pripeljala v svet LLM (Large Language Models).
